# نظام إدارة الكشافة — مدرسة القديس يوسف بالعبور
## Offline Desktop Scout Management System (SQLite)

نظام محلي آمن وموثوق لإدارة بيانات عضوات وقادة الكشافة، مصمم للعمل محلياً بالكامل بدون اتصال بالإنترنت (Offline-First) باستخدام قاعدة بيانات **SQLite** محلية.

---

### 🌟 المواصفات الرئيسية

1. **العمل بدون إنترنت (100% Offline)**:
   - لا يتطلب أي خوادم سحابية، اتصالات خارجية أو إنترنت.
   - قاعدة بيانات SQLite محلية مدمجة (`scout.db`).
   - حفظ فوري ومعاملات آمنة (Transactions) مع التراجع التلقائي (Rollback) عند الأخطاء.

2. **الأمان وصلاحيات الدخول**:
   - تشفير كلمات المرور باستخدام Hashing قوي (`bcryptjs`).
   - حماية ضد هجمات القوة الغاشمة (قفل الحساب تلقائياً بعد 5 محاولات خاطئة).
   - مستويان من الصلاحيات:
     - **مدير النظام (ADMIN)**: صلاحيات كاملة تشمل الإضافة، التعديل، الحذف، النسخ الاحتياطي، الاستعادة، إدارة المستخدمين والإعدادات.
     - **مدخل البيانات (DATA_ENTRY)**: صلاحيات مقتصرة على الإضافة، التعديل، والبحث وعرض الأعضاء (ممنوع من الحذف وتغيير الإعدادات).

3. **إدارة بيانات الأعضاء والقادة**:
   - التحقق الصارم من الرقم القومي (14 رقماً فريداً غير قابل للتكرار).
   - التحقق من الحقول الإجبارية وصحة تواريخ الميلاد وسنوات الالتحاق.
   - بطاقة عضوية كشفية متكاملة مع حساب تلقائي للعمر وزر طباعة مخصص.

4. **البحث والتقارير**:
   - بحث فوري يدعم البحث الجزئي بالاسم والبحث الدقيق بالرقم القومي.
   - فلاتر متقدمة حسب المراحل الدراسية (ابتدائي، إعدادي، ثانوي، جامعة، أخرى) والصفة (عضوة / قائد).
   - تقارير إحصائية شاملة قابلة للطباعة وتصدير CSV (Excel).

5. **النسخ الاحتياطي وسجل الرقابة**:
   - إنشاء واستعادة نسخ احتياطية لقاعدة البيانات بتنسيق: `Scout_Backup_YYYY-MM-DD_HH-MM-SS.db`.
   - جدول رقابة فوري (`audit_log`) لتوثيق جميع العمليات (LOGIN, LOGOUT, ADD, EDIT, DELETE, BACKUP, RESTORE).

### 💻 متطلبات وطريقة التشغيل

1. **التشغيل أثناء التطوير**:
   ```bash
   npm run dev
   ```

2. **بناء وتشغيل النسخة الإنتاجية**:
   ```bash
   npm run build
   npm start
   ```

3. **تنفيذ الاختبارات الآلية الشاملة**:
   ```bash
   node tests/suite.js
   ```
